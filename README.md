## Twitter App ✗

Twitter Clone is a feature-rich mobile application that replicates the core functionalities of Twitter. Built using modern iOS development frameworks and backend technologies, this app allows users to post tweets, view timelines, interact with tweets, and manage profiles. With a scalable backend powered by Node.js and MongoDB, the app ensures seamless performance and a dynamic user experience.

## ✨ Features
- **User Authentication:**
  - Secure sign-up and login with email and password.
- **Post Tweets:**
  - Create, edit, and delete tweets with text and optional image attachments.
- **Timeline Feed:**
  - A dynamically updated feed of user posts with smooth scrolling.
- **Media Support:**
  - Image upload and display using the Kingfisher library for optimized performance.
- **User Profiles:**
  - View and update profile details, including avatars and bio.
- **Offline Support:**
  - Combine framework ensures data synchronization and caching.
- **Unit Testing:**
  - Comprehensive test coverage for critical components ensures reliability and robustness.

## 🛠️ Technologies Used
**Frontend (iOS):**
- **SwiftUI:** For building declarative and dynamic user interfaces.
- **UIKit:** For integrating custom views and animations.
- **Combine:** To handle asynchronous data streams and state management.
- **Kingfisher:** For loading and caching images efficiently.

**Backend:**
- **Node.js:** Handles API requests and business logic.
- **MongoDB:** Stores user data, tweets, and media references.
